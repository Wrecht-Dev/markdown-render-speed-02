A dependency-free Markdown renderer, written from scratch, that produces byte-for-byte the same HTML as marked 18.1.3 with default options while running faster. `parse.js` holds the renderer; `main.ts` is the harness driver.

## Run it

```sh
node main.ts
```

The driver reads `/input/cases.json` (an array of `{id, markdown}`), renders each case with `parse`, and writes the HTML strings in order to `/output/html.json`.
